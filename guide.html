شروع سریع

  1. روی آیکون برنامه بزن تا باز بشه
  2. توی صفحه اصلی، ۹ بخش مختلف رو می‌بینی
  3. هر بخش رو که بخوای، روی کارت‌ش کلیک کن
  4. برای برگشت، از دکمه بازگشت گوشه بالا راست استفاده کن
  5. توی صفحه‌های داخل، معمولاً چند تب داری که با کشیدن به چپ و راست عوض می‌شن
برای استفاده راحت‌تر، از منوی پایین صفحه (۵ دکمه) می‌تونی سریع بین بخش‌های مهم جابه‌جا بشی.

این برنامه ۱۴ روز اول کاملاً آزاده. بعدش باید ثبت‌نام کنی تا ادامه بدی.

  1. از منوی پایین، روی «بیشتر» بزن
  2. روی کارت پروفایل (بالای صفحه) کلیک کن
  3. نام و شماره واتساپ خودت رو وارد کن
  4. اگه خواستی، یه عکس هم انتخاب کن
  5. روی «ذخیره پروفایل» بزن
  6. برای گرفتن کد تایید، دکمه سبز رو بزن
  7. کد ۶ رقمی که نشون داده می‌شه رو، به مدیریت ارسال کن
توجه: اگه تا ۱۴ روز پروفایل نسازی، برنامه قفل می‌شه و باید اول ثبت‌نام کنی.

برای اینکه برنامه مطابق سلیقه‌ت باشه، از بخش تنظیمات (منوی پایین ← «بیشتر») اینا رو تنظیم کن:

مسائل مالی
  1. روی «احکام من» توی صفحه اصلی بزن
  2. یا از منوی پایین، دکمه «احکام» رو بزن
  3. یه دسته رو انتخاب کن (مثلاً «نماز»)
  4. سؤال‌ها رو ببین و روی هر کدوم بزن تا جوابش بیاد
می‌تونی از تنظیمات، مذهبت رو عوض کنی (جعفری یا حنفی) تا جواب‌ها مطابق فقه تو باشه.

بیش از ۱۰۰ مقاله پزشکی در ۹ دسته‌بندی مختلف:

  1. روی کارت «سلامت بانوان» توی صفحه اصلی بزن
  2. موضوع مورد نظرت رو انتخاب کن
  3. لیست مقالات باز می‌شه
  4. روی هر مقاله بزن تا کاملش رو بخونی
  5. با دکمه‌های پایین مقاله می‌تونی کپی، اشتراک، یا صوتی گوش کنی
این مقالات صرفاً جنبه آموزشی دارن. برای تشخیص و درمان، حتماً به پزشک مراجعه کن.

یه دستیار هوشمند که بدون اینترنت کار می‌کنه و به سؤالات رایج بانوان جواب می‌ده:

  3. سؤالت رو با انتخاب دسته‌بندی یا تایپ کردن بپرس
  4. همراز سریع جواب می‌ده
کاملاً آفلاین: حتی بدون اینترنت هم کار می‌کنه چون همه سؤالات و جواب‌ها از قبل آماده شدن.

معرفی بانوان نمونه تاریخ اسلام، معاصر و افغان:

  1. روی «بانوان نمونه» توی بخش دسترسی سریع بزن
  2. از بین دسته‌بندی‌ها یکی رو انتخاب کن
  3. روی هر بانو بزن تا زندگی‌نامه، ویژگی‌ها و درس‌های زندگی‌ش رو ببینی
می‌تونی متن هر بانو رو کپی یا با صدای بلند گوش کنی.

نکات و ترفندها

  1. برای تم روشن/تاریک، آیکون ماه/خورشید بالای صفحه اصلی
  2. با کشیدن انگشت روی بخش‌ها، بین تب‌ها جابه‌جا شو
  3. روی متن انگلیسی دکمه‌ها، می‌تونی با نگه‌داشتن، ترجمه ببینی
  4. توی دعاها، با دکمه «کپی» متن رو به دوستانت بفرست
  5. با دکمه «خواندن»، مطلب با صدای بلند خونده می‌شه
  6. روی کارت روز (حکم امروز و نکته امروز) بزن تا کاملش رو ببینی
  7. توی دعاهای طولانی، سرعت پخش رو کم کن (۰.۷۵x)
  8. برای دسترسی سریع، از ۵ دکمه منوی پایین استفاده کن
  9. مطالب مهم رو با ستاره ذخیره کن تا بعداً راحت پیداشون کنی
  10. برای یادداشت‌های مهم، از رنگ‌های مختلف استفاده کن

سؤالات رایج

آیا برنامه اینترنت می‌خواد؟
نه، برنامه کاملاً آفلاین کار می‌کنه. فقط برای مشاهده ویدیوهای آموزشی و لینک‌های خارجی نیاز به اینترنت داره.
اطلاعات من کجا ذخیره می‌شه؟
تمام اطلاعات (یادداشت‌ها، چرخه قاعدگی، نشان‌شده‌ها و تنظیمات) فقط روی گوشی خودت ذخیره می‌شه. کسی بهش دسترسی نداره.
چطور می‌تونم مذهبی رو عوض کنم؟
از منوی پایین، «بیشتر» → «تنظیمات» → بخش «مذهب فقهی»، بین جعفری و حنفی انتخاب کن.
چرا ازم ثبت‌نام می‌خواد؟
برای این‌که بتونیم پشتیبانی بهتری داشته باشیم. ۱۴ روز اول آزاده، بعدش برای ادامه استفاده ثبت‌نام لازمه. اطلاعاتت محرمانه می‌مونه.
چطور می‌تونم یه مطلب رو نشان کنم؟
توی هر بخش، کنار هر مطلب یه ستاره هست. روی ستاره بزن، مطلب به «نشان‌شده‌ها» اضافه می‌شه. برای دیدنشون، فیلتر «نشان‌شده‌ها» رو بزن.
چطور می‌تونم پروفایلم رو حذف کنم؟
تنظیمات → روی کارت پروفایل بزن → دکمه «حذف پروفایل» → تایید کن. تمام اطلاعاتت پاک می‌شه.
آیا برنامه از داده‌هام نسخه پشتیبان می‌گیره؟
نه، هیچ نسخه پشتیبان ابری از اطلاعاتت گرفته نمی‌شه. اگه برنامه رو پاک کنی، همه داده‌ها از بین می‌رن. پس اطلاعات مهم رو جایی دیگه هم نگه‌دار.
