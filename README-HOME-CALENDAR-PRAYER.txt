BANOVAN NOOR — Home + Calendar + Prayer Times update

فایل‌های این بسته را با حفظ مسیرهای نسبی در ریشهٔ پروژهٔ اصلی کپی کنید:
- home.html -> ریشه؛ نسخهٔ جدید را جایگزین کنید.
- prayer-times.html -> ریشه؛ صفحهٔ جدید.
- calendar.html -> ریشه؛ نسخهٔ جدید تقویم.
- sw.js -> ریشه؛ نسخهٔ جدید را جایگزین کنید.
- data/calendar/events.json -> پوشهٔ data/calendar (اگر وجود ندارد، بسازید).
- js/prayer-times.js, js/qibla.js, js/calendar.js -> پوشهٔ js (اگر وجود ندارد، بسازید).

دیتابیس events.json از مجموعهٔ فعلی پروژهٔ بانوان نور ساخته شده و ۹۲ مناسبت دارد. فایل occasions.json حذف یا جایگزین نشده، چون صفحهٔ خانهٔ موجود هنوز از آن استفاده می‌کند.

اعتبارسنجی انجام‌شده: JSON parse؛ بررسی ارجاع‌های HTML محلی در فایل‌های جدید؛ node --check برای فایل‌های JS؛ آزمون ZIP. آزمایش روی گوشی واقعی انجام نشده است.

مهم: اوقات نماز، محاسبهٔ آفلاین تقریبی بر پایهٔ مختصات، زاویه‌های رایج و منطقهٔ زمانی است؛ برای عمل شرعی با تقویم معتبر محل تطبیق کنید. روش‌های جعفری/شافعی/حنفی تفاوت‌های فقهی و محاسباتی دارند و این ابزار جایگزین جدول رسمی مرجع دینی نیست. جهت هندسی قبله از مختصات تا کعبه محاسبه می‌شود؛ چرخش زنده وابسته به حسگر و کالیبراسیون گوشی است و ممکن است در دستگاهی پشتیبانی نشود. GPS و قطب‌نمای زنده در مرورگر معمولاً به HTTPS و اجازهٔ کاربر نیاز دارند.

نوار پایین و FAB خانه در home.html عمداً تغییر داده نشده‌اند.
